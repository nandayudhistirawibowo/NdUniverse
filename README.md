# siDeutsch

Platform belajar bahasa Jerman interaktif untuk mahasiswa Indonesia. 

## Fitur
- Dual-track learning (Alltagsdeutsch & Fachdeutsch)
- Sistem level dinamis (A1-C2)
- Kuis interaktif (XP, Nyawa, Audio, Progress)
- Dashboard Mahasiswa & Admin
- Sinkronisasi progress ke Supabase

## Tech Stack
- Astro (SSR)
- Preact
- Supabase (Auth & DB)
- Vercel
